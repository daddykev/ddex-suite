# API reference

## Rust

The crates' API documentation is generated by docs.rs:

| Crate | Documentation | What it has |
|---|---|---|
| `ddex-parser` | [docs.rs/ddex-parser](https://docs.rs/ddex-parser) | `DDEXParser`, `SecurityConfig`, the parse errors, the experimental streaming APIs |
| `ddex-builder` | [docs.rs/ddex-builder](https://docs.rs/ddex-builder) | `DDEXBuilder`, `BuildRequest` and the `*Request` structs, `BuildOptions`, `BuildError` |
| `ddex-core` | [docs.rs/ddex-core](https://docs.rs/ddex-core) | The flat and graph models (`models::flat`, `models::graph`), `ERNVersion` |

## Node.js

The packages ship TypeScript definitions; generated reference pages are planned.

- `ddex-parser`: [`index.d.ts`](https://github.com/daddykev/ddex-suite/blob/main/packages/ddex-parser/bindings/node/index.d.ts)
  (`DdexParser`, `ParsedMessage`, `JsRelease`, `JsTrack`, `JsDeal`, ...)
- `ddex-builder`: [`build-request.d.ts`](https://github.com/daddykev/ddex-suite/blob/main/packages/ddex-builder/bindings/node/build-request.d.ts)
  (the `BuildRequest` type) and
  [`index.d.ts`](https://github.com/daddykev/ddex-suite/blob/main/packages/ddex-builder/bindings/node/index.d.ts)
  (`DdexBuilder`)
