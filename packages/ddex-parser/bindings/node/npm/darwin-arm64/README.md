# ddex-parser-darwin-arm64

The macOS arm64 (Apple silicon) native binary of [`ddex-parser`](https://www.npmjs.com/package/ddex-parser), part of
[DDEX Suite](https://github.com/daddykev/ddex-suite).

Do not install this package directly: `npm install ddex-parser` installs it as an optional
dependency on matching systems. Documentation, changelog and issues:
https://www.npmjs.com/package/ddex-parser
